Mesh Fire Detection

Goals
1. Reduce wildfire detection time.
2. Radically reduce the cost of wildfire detection.
3. Maximize the area covered by the detection network.

Node types
Base: the core and connecting node. Provides the strongest possible LoRa signal.
Cellular: provides an internet connection.
Sensor: has sensors for detecting smoke.
Vision: detects smoke from images.

Deployment
How to deliver all nodes to the required locations with minimal difficulty, especially in remote areas without road access.

Placement
How and where to install the nodes.
How to mount Base nodes high above the ground.
How to position Vision nodes for effective visual coverage.

Structure
The optimal structure of a single network branch.
One Cellular node is placed at the beginning of the branch. Base nodes then form a chain extending from it, with Sensor and Vision nodes connected to the Base nodes.
No node should be critical.

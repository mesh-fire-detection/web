## Header

Four links, one button. Anything more breaks on a phone.

- **Map** — the live network
- **Build** — BOM, STLs, firmware, assembly
- **Coverage** — the calculator
- **Open Problems**
- `Build a Node` — primary button, right side
- GitHub icon, far right

If you want a fifth link, **About** goes between Open Problems and the button. Alternates worth considering: *Network* over Map, *Hardware* over Build, *Unsolved* over Open Problems.

## Two things that must be in the footer

**"Not an emergency service."** One line, every page, before the copyright. It costs nothing and it's the first thing a fire district's lawyer looks for.

**Node count.** A live counter — "14 nodes online · 3 offline" — sitting in the footer on every page. It's the cheapest possible proof the thing is real, and it makes the offline number impossible for you to quietly hide.
